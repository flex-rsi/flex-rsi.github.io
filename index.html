Overview

How far can a frontier agent improve itself?

Given a task, a fixed budget and a general-purpose starting harness, Flex-RSI measures how far a frontier agent can improve on its own: its solution, and the tools and prompts it works with. A frozen protocol runs every round, scores candidates on hidden splits, meters the budget and records each step, so results are comparable across models, tasks and domains.

Protocol

How a run works

  1. Start

    A released task, a budget and the shared starting harness.

  2. Iterate

    The agent experiments, edits its solution and refines its own tools.

  3. Accept

    Changes are kept only when hidden validation improves beyond noise.

  4. Stop

    The run ends when its budget or round limit is used up.

  5. Test

    The final solution is scored once on the hidden test split.
